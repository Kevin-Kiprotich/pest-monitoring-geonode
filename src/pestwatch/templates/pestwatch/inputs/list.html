History is uploaded; new data is downloaded. Everything before {{ fetch_from }} (weather days, satellite composite months, SEAS5 archive years) is the modelling team's history and is uploaded here. From {{ fetch_from }} on, the system downloads what Google Earth Engine and the Copernicus CDS provide: the daily weather, the monthly satellite composites (with the modelling team's recipes) and the SEAS5 forecast. Static layers, pest models, the LSTM model and incidence records are always uploaded. A composite month can still be uploaded (e.g. one Earth Engine could not make); an uploaded file is never replaced by the automatic fetch. Each file is checked and stored where the models read it. Large archives (e.g. years of daily weather) can also be copied into {{ data_root }} on the server in the same folder layout; those are kept as well.
